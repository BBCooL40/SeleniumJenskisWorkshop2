# Selenium UI Automation Practice Project

This repository contains a Selenium-based UI automation practice project created as part of my QA Automation learning path.

## Purpose

The goal of this project is to practice the fundamentals of UI test automation, automated functional testing, test execution, and CI pipeline configuration.

## Technologies Used

- C#
- .NET
- Selenium
- NUnit
- Jenkins
- Git / GitHub

## What This Project Demonstrates

- Basic Selenium UI automation structure
- Automated functional testing practice
- Test execution through a Jenkins pipeline
- Use of test artifacts in CI
- GitHub-based project organization
